## PROJECT OVERVIEW

Chromatic dispersion, the wavelength-dependent propagation of light, plays a central role in applications spanning imaging, communications, spectroscopy, and nonlinear optics. Designing photonic structures with tailored dispersion, particularly in metasurfaces and dielectric waveguides, remains a challenging inverse problem due to the highly nonlinear and non-unique relationship between geometry and optical response. Traditional approaches rely on repeated full-wave electromagnetic simulations, which are computationally expensive and limit the ability to explore large design spaces or discover novel structures.

This project introduces a machine learning framework for fast forward evaluation and inverse design of nanophotonic waveguides. A convolutional neural network (CNN) is trained as a surrogate model to approximate the forward mapping from waveguide geometry and wavelength to modal response, enabling orders-of-magnitude faster evaluation compared to numerical solvers.  ￼

To address the inverse design problem, the framework leverages a conditional diffusion model that generates waveguide geometries conditioned on desired dispersion characteristics. Unlike GAN-based approaches, which can suffer from instability and mode collapse, the diffusion model provides stable training and effectively captures the inherently multimodal mapping between optical response and structure.  ￼ The model learns to iteratively denoise Gaussian noise into physically meaningful waveguide patterns guided by a conditioning tensor encoding modal information across wavelengths.

The dataset consists of simulated dielectric waveguide unit cells represented as 32 by 32 patterns with associated modal data across 24 wavelengths, along with physical parameters such as lattice spacing and material permittivities.  ￼ This structured dataset enables both supervised training of the forward surrogate and conditional generation in the inverse model.

During inference, the diffusion model produces multiple candidate geometries for a given target optical response. These candidates are evaluated using the CNN surrogate, and the design with the lowest response error is selected. This combined generative and evaluative pipeline enables efficient exploration of the design space while maintaining physical consistency with the desired dispersion profile.  ￼

Overall, this repository provides an end-to-end system for data-driven photonic design, replacing expensive simulation loops with fast neural approximations and enabling scalable exploration of complex nanophotonic structures.

All models in this work were trained on the MIT ORCD Engaging cluster, a high-performance computing environment designed for large-scale machine learning workloads. Training was performed on nodes equipped with NVIDIA L40S GPUs, along with 64 CPU cores and approximately 1 TB of system memory per node, enabling efficient handling of large HDF5 datasets and high-throughput model optimization.

Further details on the model architectures, training procedures, and quantitative results will be provided in an upcoming paper accompanying this repository. The paper will present a complete description of the forward surrogate and conditional diffusion models, along with evaluation metrics, example designs, and analysis of performance across the test set. It will also discuss the broader implications of this approach for inverse photonic design and outline potential extensions to more complex structures and parameter regimes.
